DASHBOARD BI E-COMMERCE — ESPECIFICAÇÃO DE CONSTRUÇÃO
======================================================

TEMA
----
- Modo: Dark
- Fundo da página: #262626
- Fundo dos cartões/visuais: #323130
- Cor da fonte: #FFFFFF (branco)
- Fonte: Segoe UI
- Tamanho título: 12pt
- Tamanho valor: 24pt (cards), 10pt (tabelas)

Para aplicar o tema, criar arquivo JSON de tema personalizado:
{
  "name": "BI E-Commerce Dark",
  "dataColors": ["#4A90D9", "#50B86C", "#E8A838", "#E05A5A", "#8B5CF6", "#F59E0B", "#06B6D4", "#EC4899"],
  "background": "#262626",
  "foreground": "#FFFFFF",
  "tableAccent": "#323130",
  "visualStyles": {
    "*": {
      "*": {
        "background": [{"color": {"solid": {"color": "#323130"}}}],
        "border": [{"color": {"solid": {"color": "#1A1A1A"}}, "radius": 5}]
      }
    },
    "page": {
      "*": {
        "background": [{"color": {"solid": {"color": "#262626"}}}]
      }
    },
    "card": {
      "*": {
        "labels": [{"color": {"solid": {"color": "#FFFFFF"}}}],
        "categoryLabels": [{"color": {"solid": {"color": "#A0A0A0"}}}]
      }
    }
  }
}

FILTROS GLOBAIS (PAINEL DE FILTROS)
------------------------------------

Configurar no painel "Filtros" → "Filtros em todas as páginas":

Filtro 1 — Ano:
  Tipo: Filtro de lista (dropdown com checkbox)
  Campo: dim_calendario[ano]
  Posição: Canto superior esquerdo (sobreposto à página)
  Seleção padrão: Ambos os anos marcados
  Aparência: Fundo #323130, fonte branca

Filtro 2 — Região:
  Tipo: Filtro de lista
  Campo: dim_clientes[regiao] (ou fact_vendas[regiao])
  Posição: Abaixo do filtro de ano
  Seleção padrão: Todas as regiões

Filtro 3 — Estado:
  Tipo: Filtro de lista
  Campo: dim_clientes[estado] (ou fact_vendas[estado])
  Posição: Abaixo do filtro de região
  Seleção padrão: Todos os estados

Filtro 4 — Categoria:
  Tipo: Filtro de lista
  Campo: dim_produtos[categoria]
  Posição: Abaixo do filtro de estado
  Seleção padrão: Todas as categorias

Alternativa de layout:
  Posicionar os filtros como segmentações (Slicers) no topo de cada página,
  lado a lado, com altura ~50px, sincronizados entre páginas.
  
  Para sincronizar segmentações entre páginas:
    Selecionar segmentação → Exibir (Sincronizar Segmentações) → 
    Marcar páginas onde deve aparecer.


INTERAÇÕES E CROSS-FILTERING
-----------------------------

Configuração padrão (recomendada):
- Todos os visuais interagem entre si
- Cross-filtering ativado
- Cross-highlighting ativado

Interações específicas a ajustar:
1. Cards (Linha 1) → Editar Interações:
   - Desmarcar "Filtrar" em outros cards (cards não filtram cards)
   - Permitir filtrar gráficos e tabelas

2. Tabela de Ranking de Vendedores:
   - Selecionar um vendedor → destaca nos gráficos de faturamento
   - Selecionar múltiplos → filtra para o conjunto

3. Gráfico de Evolução Mensal:
   - Selecionar um mês → filtra período nos cards
   - Selecionar intervalo (brush) → filtra período

4. Tooltips Personalizadas:
   - Criar página de tooltip (oculta) com informações detalhadas
   - Configurar tamanho: 320px × 240px
   - Ativar em gráficos de barra e área
